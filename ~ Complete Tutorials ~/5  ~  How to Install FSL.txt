What is FSL ?

A tool that allows you to store your online save data locally, gain infinite money, and much more!  
All the money, properties, cars, and such you make while using FSL are kinda faked, they only save locally, not in Rockstar cloud.
So say if you load up without FSL injected then all the money and cars and things you made with FSL won't be there, its only there when you launch with FSL injected.

While using it don't join sessions, players invites, with FSL you have to stay within Los Santos in session that you created.

HOW TO INSTALL FSL:  (SAME PROCESS FOR BOTH LEGACY & ENHANCED)

— Start by temporaily turning Real Time Protection off in your Windows Security settings

— This is because of something called False Positives which is very common in the world of game modding, you can do more research on it to feel more comfortable if you'd like
  It is highly praised and used by many, so you don't have anything to worry about.

— Windows Search > Windows Security > Virus & Threat Protection > Manage Settings > Disable Real Time Protection 

— Minimize Windows Security 

~~~~~~~~~~~~

— Make a central folder for all GTA Mod Files so everything can be in one place.

— Download the latest FSL File from the offical page:
  https://www.unknowncheats.me/forum/grand-theft-auto-v/616977-fsl-local-gtao-saves.html

— Rename the .dll file so it's just `WINMM.dll`

— Open your GTA Game Files Folder, which can be done 3 different ways depending on what Launcher you use GTA V on:

  - For Rockstar Launcher ~ go to settings > Grand Theft Auto 5 at bottom left > View Installion Folder

  - For Steam ~ Select GTA V in your games, click the gear icon > Manage > Browse Local Files 

  - For Epic Games Launcher ~ Select the 3 Dots icon beside the game > Manage > The folder icon to the left of the Uninstall button is the Game Files Folder

— Drag the WINMM.dll into that folder. 

SUGGESTION:
— Create a shortcut to the GTA V Game Files Folder and put the shortcut in your central GTA Mod Files Folder so it's easily accessable

~~~~~~~~~~~~

— Open up Windows Security again ( Windows Search > Windows Security > Virus & Threat Protection > Manage Settings ) 

— Scroll down and click on Add or Remove Exclusions

**Make sure your central GTA Mod Files Folder is somewhere your always gonna keep it cause if you move any Excluded files or folders it'll ruin the set located path for the Exclusion**

— Add a File Exclusion to the .dll now located in your GTA Game Files (if you made the previously suggested shortcut it'll be easy to get to with that)

— IF YOU HAVEN'T ALREADY WHEN INSTALLING STAND MENU:

— Add a File Exclusion to the Stand Launchpad

— Add a Folder Exclusion to Stand Folder (if not done already)
  In the File Explorer Path Address Bar delete whats there and type "%appdata% and hit enter
  you will find the Stand Folder located in there so Add a Exclusion to it 

— Play it safe and Add another Folder Exclusion your central GTA Mod Files Folder

— You can now turn Real Time Protection back on

— Turn BattlEye OFF in Rockstar Launcher (even if you own the game on Epic games it still uses R* Launcher)
  - If you have the game on Steam, add "-nobattleye" to the launch arguments

~~~~~~~~~~~~

— Open the Stand Launchpad

— Click Launch on the Launchpad, and wait for GTA to load

— Go to StoryMode first always
