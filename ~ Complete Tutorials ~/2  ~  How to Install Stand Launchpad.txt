— Start by temporaily turning Real Time Protection off in your Windows Security settings

  - This is because of something called False Positives, you can do more research on it to feel more comfortable if you'd like
    Stand doesn't release anything that would harm your computer

— Windows Search > Windows Security > Virus & Threat Protection > Manage Settings > Disable Real Time Protection 

— Minimize Windows Security for now

~~~~~~~~~~~~

— Make a central folder for all GTA Mod Files so everything can be in one place.

— Download Stand Launchpad (Free or if you have a paid Edition)
  Go to the Stand website ( Stand.gg or .sh in your browser ) 
  If you have a paid edition of Stand then login into your account and download the Launchpad in the account page,
  All CoaLwiX features work on Stand's Free version but is Story Mode only.
  So if you haven't bought Stand then just download the Free Launchpad from the Stand's Get Started page 

— Go to account, and download the Launchpad, save it to the central Mod Files folder you created

— Open the Stand Launchpad > Click More Info > Run Anyway

— Check for Updates

— Select the Launcher you have GTA on

— Auto Inject on/off up to your preference, don't matter

— Close the Launchpad

~~~~~~~~~~~~

— Open up Windows Security again ( Windows Search > Windows Security > Virus & Threat Protection > Manage Settings ) 

— Scroll down and click on Add or Remove Exclusions

  **Make sure your central GTA Mod Files Folder is somewhere your always gonna keep it cause if you move any Excluded files or folders it'll ruin the set located path for the Exclusion**

— Add a File Exclusion to the Stand Launchpad

— Add a Folder Exclusion to Stand Folder (if not done already)
  In the File Explorer Path Address Bar delete whats there and type %appdata% and hit enter
  you will find the Stand Folder located in there so Add a Exclusion to it 

— Play it safe and Add another Folder Exclusion your central GTA Mod Files Folder

— You can now turn Real Time Protection back on

~~~~~~~~~~~~

HOW TO LAUNCH STAND:

— Open the Stand Launchpad

— If Prompted: Click More Info, Run Anyway ( only have to do this once ) 

— Check for Updates 

— Select your Launcher

— Up to your preferance between Auto or Manual Injection doesn't matter
  If Co-Loading then suggest to use Manual Inject for more control

— Click Launch on the Stand Launchpad, and wait for GTA to load

— Go to StoryMode first always

**If you chose Manual Injection then inject either in the GTA Start Menu or once loaded into StoryMode**

— Once in Story Mode and injected Stand, Press F4, Use Shift, Crtl, ↑, and ↓ arrows to move through the Menu
