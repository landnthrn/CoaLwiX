HOW TO INSTALL COALWIX:

— If you haven't already, inject & load Stand menu in game so it creates the source folders/files in `Appdata\Roaming\Stand`

— Load the Constructor Lua as well so it creates the `Constructs` folder bin

— Simply place the CoaLwiX downloaded folders & files into the corresponding places in Stand source folder located here:
  C:\Users\%USERNAME%\AppData\Roaming\Stand

— For `Profile Alterations` choose your desired type and place the folders/files inside into `Appdata\Roaming\Stand\Profiles`
  
NOTE:
— If you have your own collection/setup of Stand add-ons, don't lose them by replacing folders and such.

— The Quick TP Places may have a initial install bug where you can't use some of them by the command line, there's an easy fix :

  - Open Stand Menu navigate to World > Places > Teleport To > Saved Places

  - Simply scroll fast through all of them till your back at the top 
    If that doesn't work then spam teleport through the list of the Saved Places 

    From then on that weird initial install bug shouldn't occur again.
