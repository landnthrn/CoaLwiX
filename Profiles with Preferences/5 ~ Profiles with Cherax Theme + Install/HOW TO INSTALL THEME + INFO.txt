HOW TO INSTALL:

Everyone has their own preferences so we made different alterations for all the profiles for you to choose from, once you picked your preference (can always change it later)

Open Stand Launchpad and click Open Stand Folder

Drag or Copy the contents from inside the type of profiles you want to use, into the Stand Profiles Folder

Open Cherax Theme Folder, Open the Lua Scripts Folder

Drag or copy the 'Themes' Folder and 'Cherax V4 Theme.lua' file into the Stand Lua Scripts Folder (This Themes folder is not to be confused with the Theme Folder in Cherax Theme, its Themes folder with a S)

Back in Cherax Theme Folder, Open the Theme Folder and drag the 2 files into the Stand Theme Folder

~~~~~~~~~~~~~~~~~~~~~

IF YOU WANT TO TURN THIS OFF:

It's not as simple as changing the profiles because the Menu Font is still in the Stand Theme Folder, 

if you don't want to use it it's best to just remove all the files from the places you installed them above ^^^
